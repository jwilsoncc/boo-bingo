# Boo Bingo: Services on Hold

A scenario caller for Care Coordinator bingo on reasons to place services on hold. Players already have their own cards.

- **Stir the Cauldron** calls a random scenario. Read it aloud.
- **Reveal hold reason** shows the answer once the room has guessed.
- **Undo last call** and **New game** are there if you need them.

## Edit the scenarios
Open `index.html` and edit the `HOLDS` list near the bottom (`reason` and `scenario`).

## Publish on GitHub Pages
1. Create a repository (for example `boo-bingo`) and upload `index.html` and this README.
2. Go to **Settings > Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
3. Your link will be `https://<your-username>.github.io/boo-bingo/`.

All scenarios are fictional. Confirm against company policy before use.
